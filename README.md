# 🚀 SEO Website Template

Faqe e plotë dhe responsive për agjenci SEO: hero me slider, shërbime, portofol punësh, plane çmimesh, vlerësime klientësh dhe formë kontakti. Me dark/light mode dhe menu mobile. Ikonat Font Awesome janë zëvendësuar me unicode lokale — zero varësi të jashtme.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html, demo/css/style.css, demo/css/fa-local.css, demo/js/script.js, demo/images/
- `original/` — burimi origjinal i paprekur
- `PROVENANCE_LICENSE.txt` — provenienca dhe licenca
